# 개발용 코딩 평가: 가상 원장

이 폴더는 **의도적으로 결함이 있는 공개 개발 fixture**이며 운영용 금융 프로그램이 아니다. 평가 대상은 `baseline.py`의 `Ledger`다. 외부 코드나 데이터는 포함하지 않았다. 이 문서와 공개 테스트는 이미 노출되어 독립 최종 평가가 아니다.

## 과제

기존 `Ledger` API를 유지하며 `transfer(request_id, source, target, amount)`를 구현한다. 초기 잔액은 계좌명에서 음수가 아닌 정수로 구성된 사전이며, `snapshot()`은 내부 상태를 수정할 수 없는 독립 사전을 반환한다.

- 정상 이체는 원자적으로 두 잔액을 변경하고 `"applied"`를 반환한다.
- 같은 요청 ID와 같은 인수의 재시도는 잔액을 다시 바꾸지 않고 같은 결과를 반환한다. 같은 ID에 다른 인수를 사용하면 `ValueError`다.
- 금액은 불리언이 아닌 양의 정수여야 하며 계좌가 없거나 출발·도착이 같거나 잔액이 부족하면 `ValueError`다. 실패는 잔액과 요청 ID 기록을 바꾸지 않는다.
- 동시 이체에서도 잔액은 음수가 되지 않고 자금 총합은 유지된다. 한 요청이 실패한 뒤 같은 ID로 정당한 요청을 재시도할 수 있다.

## 평가

`python benchmarks/ledger-pilot/oracle.py`는 현재 결함이 있는 기준 구현을 검사한다. 일부 FAIL은 **의도된 음성 대조**이며 저장소 전체 테스트 결과가 아니다. 모델이 생성한 코드는 권한이 격리된 별도 실행 환경에서만 평가하고, 테스트·입력·모델 출력·실행 환경과 로그를 보존한다. 프롬프트나 폴더만으로 OS 격리가 보장되지 않는다. 성공 판정에는 이 공개 테스트 외에 사전 준비한 독립 미노출 테스트와 검토가 필요하다.
