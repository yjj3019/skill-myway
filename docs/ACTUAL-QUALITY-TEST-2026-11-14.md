# 실제 디자인·코딩 검증 계획

2026-11-14. 현재 작업본의 공개 개발용 평가다. 목표는 실제 동작과 결함을 관측하는 것이며 일반적인 모델 우열이나 개선 폭을 입증하지 않는다.

## 사전 계약

- 디자인: 같은 가상 데이터로 한국어 비교 슬라이드 하나를 자체 포함 HTML로 생성한다. 제목의 결론, 값의 정확성, 시각적 비교 관계, 텍스트 가독성·잘림을 평가한다. 실제 브라우저 렌더를 관찰하지 못하면 시각 품질은 NOT VERIFIED다.
- 코딩: 유한 의존성 그래프를 입력받아 결정적인 위상 순서를 반환하고 중복 간선, 미등록 노드, 순환을 처리하는 Python 함수. 독립 테스트가 정상·순환·중복·잘못된 입력·결정성을 확인한다. 테스트 통과는 해당 사례에 한한다.
- 각 모델에 같은 과제를 전달한다. 호출 예산은 모델별 과제당 1회, 각 180초 이내다. 인증·사용량·실행 오류는 실패 또는 미실행으로 기록한다. Grok은 미설치여서 미실행이다.
- 출력·명령 결과와 환경은 프로젝트 내 `eval-results`에 보존하고, 임의 정보·실제 고객 데이터·외부 코드와 자산은 사용하지 않는다. 사용자 승인 없는 GUI 조작·외부 저장소 쓰기는 하지 않는다.
- 자동 검사, 실행 여부, 직접 확인한 결과와 독립적인 시각·의미 평가는 분리한다. 이 공개 사례를 본 뒤 지침을 조정하면 독립 최종 검증으로 계산하지 않는다.

첫 실행의 Windows 파이프 인코딩이 한국어 요청을 손상시켰다. 해당 실행을 중단하고 결과를 평가에서 제외했다. UTF-8 파일에서 요청을 직접 읽어 모델에 전달하도록 수정해 각 모델·과제당 최대 1회 재시도한다. 디자인은 현재 스킬 본문과 관련 참고 지침을 요청에 직접 포함하며, 이는 자동 스킬 선택이나 도구 로드의 검증이 아니다. 코딩은 별도 코딩 스킬이 없는 현재 모델의 출력 평가다.

## 실제 결과

- 재실행 네 건 모두 응답했다. Claude 디자인 55.79초·코딩 38.63초, Codex 디자인 75.09초·코딩 55.60초. 종료 코드 각 0. Claude 모델 식별자는 해당 출력에서 확인하지 못했고 Codex는 CLI 이벤트상 `gpt-6.1-terra`다. Codex 출력에 `SessionStart Failed` 훅이 기록되어 환경 동등성을 확정할 수 없다. 비용은 확인하지 못했다.
- 코딩은 응답을 먼저 사람이 읽고 실행 범위를 확인했다. 정답은 후보 코드가 아닌 전체 순열 비교로 계산했고 빈 입력·중복 간선·자기 순환·100개 고정 시드 그래프·중복 노드·미등록 노드 등 **각 105개 조건**과 입력 불변성을 검사했다. 두 결과 모두 통과했다. 테스트 세부 구현은 응답을 본 뒤 작성했으며 독립 평가자·미노출 평가가 아니다. 다섯 노드 이하의 한 알고리즘 문제이므로 고난도 시스템 설계·디버깅이나 보안 역량을 입증하지 않는다.
- 디자인은 스크립트와 외부 참조가 없는 HTML을 추출해 Chrome headless 1600×900에서 실제 렌더했다. 두 결과 모두 가상 표시와 A/B/C의 6개 수치, C의 정확도·B의 속도 결론이 보였다. 자체 확인 시 Claude 출력은 두 지표를 막대와 수치로 비교하지만 정확도 차이는 작아 수치 확인에 의존한다. Codex 출력은 정렬과 대비가 명료하지만 표 중심이라 수치 간 차이와 선택의 의미가 시각적으로 약하다. 이 평가는 작성자 자신의 정성 검토이며 독립 심사나 점수 비교가 아니다. 다른 화면 크기, 접근성, HTML·PPTX 일치·편집성은 NOT VERIFIED다.
- 산출물은 로컬 `eval-results/quality-test-20261114/`에 보존한다. 원시 실행 기록과 시험 스크립트는 프로젝트 내부 `.git/quality-eval-20261114/`에 있다. 외부 에셋을 쓰지 않았으며, 이 실험의 모델 출력은 스킬·배포 코드에 편입하지 않았다.
- 기준선과 후보를 같은 조건으로 비교하지 않았으므로 디자인 스킬의 개선 효과를 판정할 수 없다. Grok, 더 어려운 실제 코드베이스 과제, 모델의 자동 스킬 로드, 독립 시각 평가와 다른 실행 환경은 미검증이다.
