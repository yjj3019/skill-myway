# AI-Harness 재검토와 적용 기록

## 기준과 범위

- 2026-11-11 기준 원본 `main` 커밋 `f8ad6d70c035d8cd8606b1aae66767b169baebac`. 이전 98파일 검토와 별도의 현행 스냅샷이다.
- 원본 트리의 파일 213개를 모두 읽어 목록·역할·라이선스 단서를 분류했다. 구성은 스킬 자산 57개, 문서 45개, 스크립트 21개, 테스트 51개, 나머지 설정·런타임·안내 39개다. 자동 분류와 관련 기능의 상세 대조이며 모든 코드 경로의 실행 검증이나 보안 감사를 뜻하지 않는다.
- 대상은 이 저장소의 9개 스킬, Claude Code·Codex·Grok Build 설치 및 평가 하네스다. 원본의 지침은 참고 자료이며 현재 사용자·호스트 지침을 대체하지 않는다.

## 라이선스와 자료 경계

- 두 저장소의 루트 라이선스는 Apache-2.0이다. 원본의 `design-evidence-harness` 하위 폴더에는 별도의 MIT 고지가 있고, 일부 문서는 제3자 스킬이나 라이선스 미확인 자료를 논한다. 루트 표시만으로 그 자산의 권리가 모두 해결됐다고 보지 않는다.
- 원본 코드·문장·프롬프트·자산은 복제하지 않았다. 쌍별 집계와 CLI 사용량 분리의 요구사항을 현재 저장소 형식에 맞게 독립적으로 작성했다. 사용자의 실제 데이터, 외부 모델 응답과 추적 원문은 저장소에 넣지 않았다.
- 새 집계 스크립트와 테스트, 기존 파일에 추가한 관련 코드·지침의 각 40자 창을 원본 213개 파일과 대조했다. 공백을 제외한 길이가 20자 미만인 창을 제외하면 신규 스크립트와 테스트는 일치 0건이며, 기존 파일의 추가분에서는 일반적인 Python 테스트 구문에 걸친 창 3건이 일치한다. 이는 해당 스냅샷에 대한 기계적 비교이며 원본이 참조한 모든 제3자 자료와의 유사성이나 법적 판단을 보증하지 않는다.
