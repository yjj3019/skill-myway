# 스킬 자동 선택 평가 (구현 상태: 모델 실행 전)

일반 평가 모드는 `case["skill"]`을 프롬프트에 지정한다. `--auto-select` 모드는 스킬명을 주지 않고 자연어 요청만 전달하지만, 실제 스킬 선택이 맞는지는 로드 이벤트 추적 없이는 확인할 수 없다. 이 문서는 자동 선택 평가의 범위와 한계를 정한다.

> 상태: **공개 케이스와 실행기 구현 완료, 실제 모델 실행·판정 미실시**. 실행 전 4절의 오염 방지 규칙을 따르고 격리·예산을 재확인한다.

## 1. 평가군 구성 (스킬명 미지정)

각 케이스에는 공개 요청과 산출물 정책만 있고 `skill`이나 정답은 지정하지 않는다.

| id | 사용자 요청 (자연어) | 확인할 점 |
|---|---|---|
| as-01 | 가상 RHEL 9 점검 결과를 고객용 Excel(.xlsx)로 작성 | 산출물 형식·사실 범위 준수 |
| as-02 | 가상 CVE 자료로 고객용 Word(.docx) 작성 | 제공값만 사용, 조사 사실을 꾸며내지 않기 |
| as-03 | 가상 장애 타임라인으로 임원용 PowerPoint(.pptx) 작성 | 관찰 사실과 추정 원인 구분 |
| as-04 | AI 소식을 조사해 글로 알려 달라고 요청, 파일 저장은 금지 | 응답만 하고 문서 파일을 만들지 않기 |
| as-05 | 첨부 없는 문서의 개인정보 점검 요청 | 첨부를 요청하고 임의 파일을 만들지 않기 |
| as-06 | 리포트 미첨부 상태에서 근거 검토 요청 | 첨부 요청, 수정 파일 생성 금지 |
| as-07 | 입력이 없는 실행 계획을 프롬프트 설계 관점에서 검토 요청 | 입력을 물어보고 문서 파일을 만들지 않기 |
| as-08 | diff 없는 코드 변경 리뷰 요청 | diff 요청, 패치 파일 생성 금지 |
| as-09 | 문단이 없는 운영 가이드 교정 요청 | 입력 요청, 파일 생성 금지 |
| as-10 | CVE 식별자 없이 RHEL 8 영향만 질문 | 식별자를 묻고 파일 생성 금지 |

**정답 가이드(기대 스킬·조합)는 이 저장소에 두지 않는다.** 실행 전 로컬 보관 파일에서만 대조한다(4절).

**부정 사례**: 스킬이 없어도 되는 요청에서 불필요한 파일을 만들지 않는지, 질문 모드 요청에서 리포트 대신 대화 응답인지 확인한다.

**정답 가이드에서 확인할 것**: 요청에서 정보가 부족한 경우 필요한 입력을 먼저 묻는지, 자료에 없는 사실을 꾸미지 않는지 확인한다. 현재 출력 검사만으로 사실 정확성이나 적절한 추가 질문을 자동 판정하지 않는다.

## 2. 판정 기준

- **선택 정확성**: 비공개 정답 가이드와 플랫폼 호출 추적이 확보된 경우에만 판정한다. 현재 실행기가 기록하는 산출물 유무는 스킬 선택의 정확성을 증명하지 않는다.
- **조합 순서**: 조사(rhel-cve·research-brief·incident-rca) → 생성(office-docs·writing) 순으로 수행되는지.
- **하드 실패**: EVALUATION.md 기준(민감정보 노출, 검증 통과 위조, 형식 무시, 지시 주입 실행)을 그대로 적용.
- **환경 기록**: 모델·도구·스킬 본문·요청 해시·실행 시각·실패/미실행 분모.

## 3. 실행기

`tests/eval_cases/auto_select_cases.json`에는 공개 요청, 산출물 정책, 예상 확장자만 둔다. 비공개 기대 스킬은 입력에 결합하지 않는다. 명확한 파일 요청은 지정 형식의 산출물 생성을, 대화 전용 요청은 파일 미생성을 검사한다.

```text
python3 scripts/run_eval.py --auto-select --platform codex --dry-run
python3 scripts/run_eval.py --auto-select --platform codex --out <빈-결과-폴더> --max-calls 10 --timeout 300
```

- `--auto-select`는 `workspace-write` 샌드박스를 명시하는 Codex CLI 실행으로만 허용한다. Claude·Grok은 이 모드에서 거부한다. 이 CLI 설정은 워크스페이스 쓰기 범위만 요청하며 OS/VM 수준 격리나 네트워크 차단을 입증하지 않는다. 평가가 산출물을 요청하므로 결과 경로에는 모델이 만든 파일이 기록될 수 있다. 실행자는 출력 폴더에 민감 자료가 없는지 확인한다.
- 자동 선택용 임시 작업 폴더의 `.agents/skills`에는 스킬 복사본만 둔다. Codex는 일반 프롬프트에서 스킬 경로를 안내받지 않으며 도구를 통해 해당 스킬 파일을 실제로 읽었는지 자동 추적하지 못한다. 결과 파일은 최대 50개·100 MiB까지 별도 경로에 보존하고 SHA-256을 기록한다. 심볼릭 링크와 `.agents`·`.grok` 스킬 복사본은 수집하지 않는다.
- 일반 타깃 평가에서 파일 산출물 검사도 요청하려면 Codex/Grok과 `--inspect-artifacts`를 사용한다. Claude는 플러그인 스킬 경로가 작업 폴더 밖이어서 이 검증 모드에서 거부한다. 수집된 PPTX/DOCX/XLSX는 재열어 구조를 검사하고 ZIP 경로·크기·압축률·매크로·외부 관계를 확인한다. 외부관계·매크로·구조 실패는 실행 실패로 판정한다. XLSX 수식 캐시가 없으면 실행은 계속되더라도 계산 상태는 `NOT VERIFIED`로 기록하고 자동 완료 판정에 포함하지 않는다. sidecar 시각 렌더링은 별도 단계다. 이 검사는 Office 전체 보안·렌더링 품질을 보증하지 않는다.
- 모든 실제 평가 실행은 `--max-calls` 또는 `--max-seconds` 중 정확히 하나를 요구한다. 둘 다 지정하거나 양수가 아니면 거부한다. `--dry-run`에는 예산이 필요하지 않으며 모델을 호출하지 않는다. 결과는 호출 수와 경과 시간을 기록하고 한도 도달 시 미실행 분모를 보존한다.
- `summary.json`은 공개 요청 해시, 케이스 파일 해시, 스킬 파일 해시, 실행기 해시, 실행 시각, 호출 예산·실행량·실패·미실행, 산출물 파일 해시를 보존한다. 전체 텍스트 응답은 각 케이스 `.md` 파일에 저장한다. 요청은 가상 공개 사례만 사용한다. 모델·CLI의 정확한 버전은 이번 구현에서 자동 수집하지 않으므로 별도 실행 환경 기록이 필요하다.
- 실제 스킬 로드 이벤트를 얻을 수 없으면 `selection_status: unverified`로 기록한다. 모델이 스스로 보고한 스킬명은 실호출 증거로 간주하지 않는다.
- 실제 모델 실행은 별도 실행 전 권한·격리·예산 확인을 거친다. 네트워크 차단과 OS/VM 격리는 이 실행기로 보장하지 않는다.

### 호출 사실의 판정 순서 (자기 보고 ≠ 실호출)

모델이 답변에 "X 스킬을 사용했다"고 써도 실제로 그 지침을 읽었는지는 확인되지 않는다. 다음 순서로 확인하고, 추적이 없으면 확정하지 않는다.

1. **플랫폼 이벤트·도구 추적을 우선한다.** 스킬 로드 이벤트, 지침·참조 파일 접근 기록, 도구 호출 기록을 수집한다.
2. 접근 기록이 있으면 그 파일과 호출 시각을 함께 근거로 남긴다.
3. **추적이 없으면 결과만으로 호출 여부를 확정하지 않고 `선택 여부 미확인`으로 기록**한다.
4. 스킬 호출 여부와 최종 답변의 업무 품질을 **각각** 평가해 분리 보고한다.

예: as 실행 결과에서 모델이 "rhel-cve 사용"을 말했어도, 플랫폼이 Skill Load 이벤트를 제공하지 않으면 `선택 여부 미확인(자기 보고)`로 기록한다. 이 구분을 지난 4케이스 기록에 적용하면 모두 자기 보고 기준이다.

## 4. 오염 방지와 보관

- 케이스 요청과 판정 가이드(정답)는 **같은 저장소에 두지 않는다**. 이 문서의 1절 표는 요청과 확인 항목만 담는다. 정답 스킬·조합은 실행 전 저장소 밖 로컬 파일에 보관해 모델 프롬프트·스킬 지침에 노출되지 않게 한다.
- 공개 케이스는 개발·회귀용으로만 쓰고, 최종 확인은 미노출 사례로 한다. 고객·실사례 식별자를 사용하지 않고 합성 자료만 쓴다.
- 사례별 "실행 여부·실패·미실행 수"와 환경을 기록해야 VERIFIED로 표시할 수 있다. 그 전까지 이 설계의 수행 결과는 NOT VERIFIED다.

## 5. 이 문서의 검증 기준

- `auto_select_cases.json`에는 공개 요청 10건, 산출물 정책·형식만 있고 정답 스킬·조합은 포함하지 않는다.
- `run_eval.py` 테스트에서 `--auto-select`의 프롬프트에 스킬명이 주입되지 않고, 필수 예산이 적용되는지 확인한다.
- 실제 모델 실행과 플랫폼 제공 스킬 로드 흔적이 확보되기 전까지 선택 품질과 실제 스킬 호출은 NOT VERIFIED다. 현재 Codex 경로는 로드 이벤트를 수집하지 않으므로 선택 여부 미확인이 기본 결과다.
