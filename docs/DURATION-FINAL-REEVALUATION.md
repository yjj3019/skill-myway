# 장애 시간 지침 최종 재평가 계약

대상은 1.16.5 작업본 `incident-rca`의 마지막 제목 조건 보강이다. 공개 개발 사례 `incident-rca-critical-duration-01`을 Claude·Codex에 각 1회, 120초 제한으로 실행한다. 직전과 같이 스킬 본문을 직접 제공하므로 자동 로드·참고 파일 활용은 검증하지 않는다. 실제 제품의 독립 평가나 일반적인 향상률을 뜻하지 않는다.

사전 판정: (1) 35분을 시작부터 완화까지의 경과로 구분하고 날짜·시간대가 불명확하면 계산에도 조건을 표시, (2) 완전 복구 시각이 없어 총 지속 시간의 상한이나 확정값으로 단정하지 않음, (3) 완화가 완전 복구보다 앞서는지 불명확하면 총 기간의 하한을 무조건 확정하지 않음, (4) 영향이 연속됐다는 근거 없이 누적 영향 시간 하한을 단정하지 않음. 제목과 본문이 모순되거나 불필요한 출력 표식이 있으면 별도 결함으로 기록한다. 실패·시간 초과와 미확인을 구분한다.

## 결과

- Claude 1회(48.28초)·Codex 1회(56.93초), 모두 종료 코드 0. 두 호출은 같은 사례를 사용했으며 `incident-rca/SKILL.md`의 실행 전후 SHA-256이 같았다. Claude의 모델 식별자와 비용, 실제 자동 스킬 선택·reference 로드는 확인하지 못했다.
- Claude는 35분에 `조건부 확정`을 붙이고 같은 날짜·시간대 전제를 바로 설명했다. 총 지속 시간의 상한·하한을 무조건 단정하지 않았고, 누적 영향 시간의 연속성도 미확인으로 두었다. 이전 응답에 있던 불필요한 영문 표식은 이 응답에서 관찰되지 않았다. `조건부 확정`은 조건이 제목에 드러나지만 독자에 따라 확정으로 오해할 여지가 있어 표현 개선 후보로 남긴다.
- Codex는 35분을 같은 날짜·시간대라는 조건부 계산으로 기재했고 총 지속 시간의 상한과 하한을 확정하지 않았다. 누적 영향 시간은 별도 항목으로 설명하지 않았으며, 이에 대한 모델의 독립적인 판단은 확인하지 못했다. 사용자 질문이 누적 영향 시간을 명시적으로 요구하지 않은 점도 함께 기록한다.
- 두 응답의 확인한 범위에서 사전 금지 조건 위반은 발견되지 않았다. 다만 Claude의 `조건부 확정` 표현과 Codex의 누적 영향 설명 범위를 위와 같이 남긴다. 작성자의 단회 자체 검토이며 별도 평가자의 판정은 없다. 이미 노출된 개발 사례에서의 재평가이므로 재발 확률·일반적 품질 향상·모델 우열을 입증하지 않는다.
- 결과는 프로젝트 내부 `eval-results/duration-final-20261114/`에 보존한다. 도구 접근 정책, 플랫폼 설정, 모델 버전은 완전히 동일하다고 확인하지 못했다. Grok, 미노출 사례 및 자동 스킬 로드는 미검증이다.
