# 저장소 검토: 평가와 실행 경계 (2026-11-14)

범위는 스킬 마켓플레이스의 지침·라이선스 기록·쌍별 비교·후속 대화·프로세스 관리 코드와 관련 테스트다. 모든 스킬의 실제 모델 품질이나 모든 외부 저장소를 검증한 전수 감사는 아니다. 외부 저장소는 공개 설명을 읽었으며 코드를 설치하거나 실행하지 않았다. 출처와 재사용 범위는 `LICENSES.md`에 기록한다.

| 우선순위 | 관측 및 영향 | 조치 또는 남은 검증 |
| --- | --- | --- |
| 높음 | 쌍별 집계의 기존 조건에는 모델·예산·도구·공통 프롬프트가 없어 조건이 달라도 선언 일치로 나올 수 있었다. | 기존 입력은 네 항목을 누락으로 보고, 확장된 스키마에서 각 조건의 차이를 집계한다. 선언은 실행 증거가 아니다. |
| 높음 | POSIX 프로세스 그룹 밖으로 벗어난 자손은 그룹 종료의 관리 범위에 들지 않는다. | 기존 한계를 유지한다. 실제 격리 보장은 운영 환경에서 별도 검증이 필요하다. |
| 중간 | 형식 검증·자기 선언 리뷰는 내용의 정확성, 독립성, 시각적 품질을 증명하지 않는다. | 자동 검사와 별도 평가를 구분하는 기존 계약을 유지한다. 실제 모델과 독립 리뷰 결과는 이번 조사에서 확인하지 않았다. |
| 중간 | 라이선스 표시와 패키징 검사는 원본 기여자의 권리나 공개 이력을 확정하지 못한다. | 기존 미확인 계보를 보존하고 외부 자료의 표현이나 파일을 가져오지 않는다. 권리 검토와 원본 확보는 미완료다. |
| 중간 | 정적 스캐너는 단서 탐지 수단이며 설치·실행을 막는 보안 경계가 아니다. | 별도 외부 도구를 설치하지 않았다. 필요하면 보유 환경과 오탐·미탐 기준을 정한 뒤 평가한다. |

모델 버전, 도구 설정, 예산 등 확장된 비교 조건 역시 입력자가 작성한 식별자다. 해시나 원본 실행 기록과 자동으로 연결되지 않으며 동일 값이 실제 동등한 환경을 보증하지 않는다. 과거 스키마의 `context_status` 변경은 보수적인 호환성 변경이므로 이를 소비하는 자동화의 기대값을 점검해야 한다.
