# 스킬·평가 하네스 경계 시뮬레이션 10건

기준: 2026-11-14 로컬 작업본, Python 3, `tests/eval_cases/cases.json`. 모델 호출 없이 가상 답변·입력과 모의 파일 읽기를 사용한 단위 수준 시험이다. 전체 스킬의 실제 응답 품질이나 운영 환경을 평가한 결과는 아니다. 아래 자동 PASS는 의미 검증이 아니라 `dialogue_eval.auto_check`의 문자열 기반 판정이다.

## 개선 우선순위

1. **높음 — 평가 이력 무결성:** 참고 파일 등 실제 스킬 실행에 영향을 주는 파일을 manifest에 포함하고, 어떤 파일이 해시 대상인지 명확히 한다. 기존 manifest와의 호환성·링크·동시 변경 경계도 검토한다.
2. **높음 — 의미 품질의 오인:** 자동 문자열 결과를 의미 품질로 승격하지 않는 기존 분리를 유지하고, 원문·출력 근거를 결부한 수동 또는 독립 평가를 실제로 실시한다. 문자열만 추가해 전체 의미를 판정한다고 주장하지 않는다.
3. **중간 — 입력 계약 엄격화:** 버전의 정확한 정수형, 필수 필드 누락, 알 수 없는 키와 중복 JSON 키를 검토해 오류를 명시한다. 기존 유효 입력과 호환성을 테스트한다.
4. **미검증 — 실제 운용:** Claude·Codex·Grok의 실제 스킬 로드·모델 응답, 독립 평가, 시각 렌더와 격리 환경은 이 10건으로 확인하지 않았다.
