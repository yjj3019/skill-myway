# 평가 하네스 수정 후 기능별 시뮬레이션

2026-11-14 로컬 작업본에서 실행한 가상 사례와 자동 회귀 테스트다. 실제 모델을 호출하거나 독립 평가자를 실행하지 않았다.

| 기능 | 재현한 입력 | 확인 기준 |
| --- | --- | --- |
| 스킬 파일 이력 | 참고 문서 추가·내용 변경·삭제 | 파일별 해시와 트리 해시가 달라지고 삭제 후 원래 구성으로 돌아오면 원래 해시와 일치 |
| 링크 경계 | 스킬 내부 파일을 링크로 취급하는 모의 입력 | 이력 생성 거부. Windows 재분석 지점도 파일 속성을 확인하나 실제 모든 파일 시스템을 시험하지는 않음 |
| 버전 계약 | 불리언 버전 | 입력 거부 |
| 필수 필드 | `required` 누락 | 입력 거부 |
| 알 수 없는 필드 | `max_char` 오타 | 입력 거부 |
| JSON 파싱 | 최상위·중첩 객체의 중복 키 | 읽기 거부 |
| 선택 필드 | 잘못된 산출물 정책과 확장자 | 입력 거부 |
| OCR·검색·표 의미 | 이전 잘못된 가상 답변 3건 | 자동 문자열 검사는 여전히 통과할 수 있지만 전체 `passed`는 `null`, 품질은 `NOT VERIFIED` |
| 예산 비교·리뷰 선언 | 다른 예산과 근거 없는 자기 선언 | 기존 기능의 미검증 처리를 유지하는 회귀 테스트 |

실행 범위와 테스트 수는 `VERIFICATION.md`에 기록한다. 문자열 검사가 문맥을 이해하거나 위조 문장을 자동으로 검출하는 것은 아니다. 실제 모델 응답의 정확성, 독립성, 실제 스킬 파일 로드와 원자적 파일 스냅샷은 별도 확인이 필요하다. manifest 1과 요약 3을 읽는 소비자는 각각 manifest 2와 요약 4에 맞게 수정해야 한다.
