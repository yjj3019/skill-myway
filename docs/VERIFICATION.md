## 설치 진단·배포·재실행 검증

- 직접 설치는 임시 홈에서 설치한 본문을 진단하고, 본문 하나가 빠진 상태와 다른 플랫폼 경로를 구분하는 회귀 사례를 추가했다. 블라인드 키 저장 실패 시 교체된 패킷 보존, 공백이 있는 입력·출력 경로에서 모의 평가 재실행을 검사한다.
- ZIP 두 개 중 두 번째에 저장 오류를 주입했다. 첫 ZIP을 보존하고 완료·미완료 목록을 출력했으며 남은 ZIP만 재시도해 두 파일을 얻었다. 임시 Git 저장소에서는 깨끗한 HEAD가 통과하고 스테이징한 추적 파일 변경은 검증에 실패했다.
- 독립 품질 평가는 NOT VERIFIED다. `docs/quality-pilot-ledger.json`을 비교 도구로 읽어 writing·incident-rca의 예정 4쌍, 판정 0쌍, 미완료 4쌍을 확인했다.

## 대조 보고의 판정 차이와 부분 입력

- Windows에서 비교 도구 테스트 23건이 통과했다. CLI에서 실패와 미확인의 차이 1건, 양쪽 모두 유효하지 않은 통과 수의 차이 0건을 확인했다. 기존 파일을 출력 디렉터리로 지정하면 오류 경로와 종료 코드 1을 반환했다.
- 여섯 상태 건수 각각에 미확인·0·1·2를 넣은 4,096개 입력에서 건수 관계를 검증했다. 알려진 값들을 유지하면서 유효한 상태 분할을 만들 수 있는 경우와 검사 결과가 일치했다.
