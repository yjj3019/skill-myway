# PDF 작업

PDF 읽기·생성·변환을 요청받았을 때의 기준이다. 렌더·폼·OCR은 환경 도구에 따라 가능 여부가 달라진다.

## 읽기

- 텍스트 추출은 페이지 단위로 하고, 표는 열·행 구조를 확인한다.
- 스캔 PDF는 OCR이 필요하다. OCR 결과는 원본과 대조하고, 저신뢰 줄은 버리거나 `확인 필요`로 표시한다.
- 판본이 여러 개면 기준 PDF의 페이지 수·발행일을 먼저 확인한다. 추출 쪽번호는 원본에서 다시 확인한다.

## 만들기·편집

- 병합·분할·회전·페이지 삭제는 원본 사본에서 작업한다.
- 워터마크·머리글은 기존 페이지 내용을 가리지 않게 배치한다.
- 폼 채우기는 필드 이름·타입을 확인하고, 채운 뒤 다시 열어 값이 유지되는지 본다.
- 암호화·권한 설정이 있으면 저장 후 열기 권한을 시험한다.

## 검증

| 항목 | 확인 |
|---|---|
| 페이지 | 페이지 수, 순서, 회전 |
| 텍스트 | 추출 텍스트가 원본과 일치하는가 |
| 표 | 열·행·단위가 유지되는가 |
| 이미지 | 해상도 저하·잘림이 없는가 |
| 폼 | 필드 값 유지, 필수 항목 누락 |
| 보안 | 암호·권한, 메타데이터의 개인정보 |

- 렌더러가 없어 시각 확인을 못 했으면 `미검증`으로 보고하고 통과로 쓰지 않는다.
- 화면용과 인쇄용은 여백·페이지 크기를 다르게 볼 수 있다.

## 공식 문서 스킬

Claude Code에서는 공식 document skills(PDF·DOCX·PPTX·XLSX)를 마켓플레이스에서 설치해 쓸 수 있다. 이 저장소는 그 구현을 복사하지 않고 설치·사용만 안내한다.

```text
/plugin marketplace add anthropics/skills
```

설치 가능 여부와 사용 조건은 해당 저장소·계정 정책을 따른다. Codex·Grok 등 다른 호스트에서는 해당 환경의 문서 도구를 사용한다.

## 주의

- 원본 보존: 덮어쓰지 않고 새 파일명으로 저장한다.
- 개인정보·자격증명·내부 주소가 메타데이터·주석·첨부에 남지 않게 확인한다.
- 스캔 OCR 결과를 원본 확인 없이 인용하지 않는다.
