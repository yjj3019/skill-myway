# research-brief

결정에 쓸 수 있는 근거 묶음을 만든다. 결론보다 출처와 한계를 먼저 세운다.

## 0. 질문 정의

- 이 조사로 무엇을 결정하는지, 범위와 제외 범위, 기준일을 정한다.
- 답이 하나로 정해지지 않는 질문이면 쟁점별로 나눈다.
- 비밀·내부 자료가 필요한 범위는 다루지 않고, 필요한 항목을 따로 밝힌다.

## 1. 출처 등급

| 등급 | 예 | 사용 |
|---|---|---|
| 1차 | 공식 문서·원 데이터·법령·릴리스 노트 | 결론의 직접 근거 |
| 2차 | 전문 매체·리뷰·분석 보고서 | 해석·맥락 보강 |
| 3차 | 요약·커뮤니티·위키 | 단서. 단독 근거로 쓰지 않음 |

각 주장에 등급, 기준일, 원문 링크를 붙인다. 번역한 자료는 번역임을 표시한다.

## 2. 수집

- 공식 자료를 먼저 보고, 모자랄 때 2차로 넓힌다.
- 날짜·버전·지역·대상을 명시한다. 오래된 자료는 "당시 기준"으로 표시한다.
- 상충하는 자료는 하나를 고르지 말고 둘 다 기록하고 차이를 설명한다.
- 출처를 열지 못했으면 열지 못했다고 쓴다.
- 사용자가 전달한 요약만 있으면 그 요약을 제공된 주장으로 표시한다. 출처 유형이 공식 문서라는 설명만으로 원문 열람·내용 일치·지원 여부가 확인됐다고 쓰거나 신뢰도를 높음으로 확정하지 않는다. 원문을 확인하기 전에는 자료의 실재·내용을 미확인으로 둔다.

## 3. 판단

- 사실, 해석, 추정을 문단이나 표에서 분리한다.
- 확신도(높음·중간·낮음)와 그 이유를 적는다.
- 반대 사례·반증을 한 번 이상 찾아본다.
- 수치·날짜·비율은 원문 표기와 단위를 유지한다.

## 4. 출력

1. 핵심 결론 1~3개.
2. 근거 표: 주장, 출처, 등급, 기준일.
3. 상충·불확실성과 그 영향.
4. 다음 확인 항목과 담당 범위.

## 5. 금지

- 출처 없는 단정, 수치·날짜·인용의 창작.
- 오래된 자료를 최신처럼 쓰기.
- 검색 결과 요약을 1차 근거처럼 쓰기.
- 유료·비공개 자료를 읽은 것처럼 인용하기.
- 조직·개인을 특정할 수 있는 정보를 근거에 남기기.
