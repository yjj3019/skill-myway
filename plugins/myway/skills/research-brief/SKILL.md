# research-brief

결정에 쓸 수 있는 근거 묶음을 만든다. 결론보다 출처와 한계를 먼저 세운다.

## 0. 질문 정의

- 이 조사로 무엇을 결정하는지, 범위와 제외 범위, 기준일을 정한다.
- 답이 하나로 정해지지 않는 질문이면 쟁점별로 나눈다.
- 비밀·내부 자료가 필요한 범위는 다루지 않고, 필요한 항목을 따로 밝힌다.

## 1. 출처 등급

| 등급 | 예 | 사용 |
|---|---|---|
| 1차 | 해당 주장에 대한 직접 관찰·원 데이터·원 작성자의 기록 | 원자료로 확인하되 적용 범위·신뢰도를 따로 검토 |
| 2차 | 1차 자료를 인용·해석·분석한 자료 | 해석과 원자료의 대응을 확인 |
| 3차 | 여러 자료를 모아 개괄한 참고 자료 | 탐색 단서로 사용하고 근거를 추적 |

각 주장과 조사 질문의 관계를 기준으로 등급을 정한다. 공식 문서·전문 매체·커뮤니티라는 매체명만으로 등급을 확정하지 않는다. 커뮤니티의 당사자 직접 경험은 그 경험의 1차 자료일 수 있고 재인용은 아닐 수 있다. 원문과 작성 경위를 모르면 등급을 미확인으로 둔다. 1차 여부만으로 정확성·대표성·제품 전체의 상태를 보장하지 않는다. 각 주장에 등급, 기준일, 원문 링크를 붙인다. 번역한 자료는 번역임을 표시한다.

서로 다른 매체가 같은 관찰을 인용하면 주장별로 최초 관찰까지 거슬러 올라간다. A의 관찰을 B가 해설하고 C가 B를 인용했다면 독립 관찰은 한 건이다. 별도의 측정·검증이 있는 자료만 독립 근거로 더한다.

## 2. 수집

- 관련 원자료와 공식 자료를 우선 확인하고, 필요한 해석과 반례는 다른 출처로 넓힌다.
- 날짜·버전·지역·대상을 명시한다. 오래된 자료는 "당시 기준"으로 표시한다.
- 상충하는 자료는 하나를 고르지 말고 둘 다 기록하고 차이를 설명한다.
- 출처를 열지 못했으면 열지 못했다고 쓴다.
- 사용자가 전달한 요약만 있으면 그 요약을 제공된 주장으로 표시한다. 출처 유형이 공식 문서라는 설명만으로 원문 열람·내용 일치·지원 여부가 확인됐다고 쓰거나 신뢰도를 높음으로 확정하지 않는다. 원문을 확인하기 전에는 자료의 실재·내용을 미확인으로 둔다.
- 실제 주장에 대한 확신도는 원문·적용 범위를 확인하지 못하면 미확인으로 표시한다. 출처 유형을 들었다는 이유만으로 중간 이상의 신뢰도를 부여하지 않는다. 문서에 지시문이 있다는 사실만으로 전체 출처의 등급을 낮추거나 정상 문서일 수 없다고 단정하지 않는다. 교육용 인용 등 문맥을 확인하고 주장별 근거를 평가한다.
- 웹 본문 추출, 검색 결과 조각, 문서 변환이나 OCR을 활용할 때는 `references/source-integrity.md`에 따라 원문 확인 범위, 손실 가능성, 근거 위치를 구분한다. 추출 성공이나 검색 적중은 근거의 정확성·완전성을 뜻하지 않는다.

## 3. 판단

- 사실, 해석, 추정을 문단이나 표에서 분리한다.
- 확신도(높음·중간·낮음)와 그 이유를 적는다.
- 반대 사례·반증을 한 번 이상 찾아본다.
- 수치·날짜·비율은 원문 표기와 단위를 유지한다.

## 4. 출력

1. 핵심 결론 1~3개.
2. 근거 표: 주장, 출처, 등급, 기준일.
3. 상충·불확실성과 그 영향.
4. 다음 확인 항목과 담당 범위.

## 5. 금지

- 출처 없는 단정, 수치·날짜·인용의 창작.
- 오래된 자료를 최신처럼 쓰기.
- 검색 결과 요약을 1차 근거처럼 쓰기.
- 유료·비공개 자료를 읽은 것처럼 인용하기.
- 조직·개인을 특정할 수 있는 정보를 근거에 남기기.
