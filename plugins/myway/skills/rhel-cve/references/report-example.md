# CVE-2099-00001 - 패키지 ParserX의 입력 처리 취약점

보안등급

Impact : Important
CVSS v3 Base Score : 7.5 (Red Hat 기준)

기준일 : 2099-08-10 (가상 자료, 공개일 2099-07-01, CISA KEV 등재 2099-07-15)

Environment
-----------

* Red Hat Enterprise Linux 9 (가상 예시)

### 1. 취약점 개요

* **분석 대상 제품**
  * RHEL 9: 영향 있음(Affected) — parserx-3.1.2-1.el9.x86_64와 이후 버전으로 수정 (RHSA-2099:4201)
* "ParserX의 입력 값 처리 과정에서 검증이 누락되어 원격 공격자가 프로세스를 중단시킬 수 있습니다." (가상 Red Hat 설명)
* 원인: 입력 값 검증 누락. 공격 조건: 네트워크 접근 가능. 업스트림 수정 버전 3.2.0. 발견자: 가상 연구자.

### 2. 영향

* 기본 구성과 미설치 환경에서는 영향이 없습니다.
* Red Hat 벡터는 CVSS:3.1/AV:N입니다. NVD 점수는 가상 자료로 병기하지 않습니다.

### 3. 완화 방법(Mitigation)

* Red Hat 완화 안내를 의역: 패치 적용 전에는 신뢰할 수 없는 입력을 차단합니다.
  ```bash
  sudo dnf update parserx
  ```
* 업데이트 후 프로세스 재시작이 필요합니다.
* 완전한 해결은 패치뿐입니다.

### 4. 추가 정보

* EPSS 0.02, 백분위 30, 기준일 2099-08-09. CISA KEV 등재(2099-07-15)입니다.
* Red Hat 데이터 특이사항: 수정 빌드(2023-07 발행)의 업스트림 버전이 업스트림 수정 버전(3.2.0)보다 이전 버전입니다. 버전 비교에 근거한 판단이며 Red Hat 공지 문구가 아닙니다.
* JSON·XML 일치: RHSA-2099:4201 항목 일치. RHSA 확인 범위: RHEL 9 기본 스트림 1개.
* Red Hat 공지에는 악용 사례가 명시되어 있지 않습니다. 악용 근거는 CISA KEV 등재입니다.

### 5. 결론

* RHEL 9 사용자는 패치를 우선 적용합니다. 미패치 스트림은 없습니다. 악용 근거는 CISA KEV 등재입니다.
