# 이미지 아트 디렉션

이미지가 독자의 이해나 인상을 실제로 돕는지 먼저 판단한다. 사용자가 제공한 자산·브랜드와 사용 범위를 우선하고, 외부 이미지·글꼴·아이콘은 용도별 권리와 고지를 확인한다. 권리를 확인하지 못한 자산은 재배포하지 않는다.

## 제작 브리프

이미지의 역할(표지, 설명, 배경, 제품 상황), 대상 독자, 전달할 감정과 메시지, 장면의 주체·행동, 시점·거리, 조명·질감, 여백과 출력 비율을 정한다. 인물·제품·장소를 실제로 촬영하거나 취재한 것처럼 만들지 않는다. 사용자 요청이나 대상 플랫폼에 맞는 이미지 생성 도구가 있다면 그 기능과 권한 범위에서 제작한다.

텍스트를 넣을 영역을 확보하고 핵심 라벨·수치·브랜드명은 생성 이미지가 아닌 편집 가능한 요소로 배치한다. 복잡한 기술 구조, 정확한 로고와 수치 그래프는 필요한 경우 벡터·도형·차트로 만들고 출처와 연결한다. 생성 이미지 내부 문자를 사실이나 실제 제품 화면의 증거로 사용하지 않는다.

## 검토

최종 표시 크기와 주변 텍스트를 함께 보고 시선이 핵심으로 향하는지, 과한 장식·복잡한 배경이 글자를 방해하지 않는지, 화면의 크롭 후 중요한 피사체가 남는지 확인한다. 손·문자·제품 형태 등 생성 오류와 화면 밖 정보 손실도 확인한다. 가독성·접근성과 역할이 불충분하면 방향을 고쳐 다시 만든다. 실제 이미지나 렌더를 보지 않았다면 완성도·결함을 관찰했다고 쓰지 않는다.
