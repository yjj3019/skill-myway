# 시각 검토 기준 선택

실제 결과를 볼 수 있을 때만 평가한다. 매체·청중·목표와 검토 대상 버전, 캡처 범위·크기, 렌더러와 확인하지 못한 상태를 기록한다. 주관적 선호와 사실 오류를 구분한다.

## 선택형 배점 예시

사용자가 점수 비교를 요청하고 평가자와 기준을 사전에 정한 경우에만 아래 예시를 사용할 수 있다. 필수 기준이나 보편적 합격점이 아니다.

| 관점 | 최대점 |
| --- | ---: |
| 구도 | 20 |
| 정보 위계 | 15 |
| 색채 | 15 |
| 여백과 정렬 | 15 |
| 독창성 | 15 |
| 전달력 | 15 |
| 렌더 품질 | 5 |

독창성은 요청한 브랜드·관습과 접근성을 깨는 정도로 평가하지 않는다. 점수별 판단 기준, 평가자와 검토 조건을 실행 전에 정하고 실제 관찰 위치를 남긴다. 이미지나 필수 화면이 없으면 해당 항목은 미평가로 두고 임의의 0점이나 만점으로 채우지 않는다.

기술 도식은 노드와 연결의 의미, 화살표 방향, 텍스트 가독성과 겹침을 별도로 확인한다. 필수 내용의 왜곡·잘림은 총점이 높아도 해결해야 한다. 화면 이미지의 점수는 조작 가능성, 스크린리더, 실제 독자의 이해도나 사실 정확성을 보증하지 않는다.
