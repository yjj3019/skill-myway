# 정보 구조와 시각 구성

청중이 알아야 할 결론과 그 근거를 먼저 정한다. 장식이나 배경은 정보의 우선순위를 강화할 때만 쓴다. 표지와 색만 바꾸고 본문의 내용 배치가 그대로라면 콘텐츠 표현 개선으로 보지 않는다.

## 질문에 맞는 구조

| 독자의 질문 | 우선 검토할 구조 | 의미 보존 확인 |
| --- | --- | --- |
| 무엇이 다른가 | 같은 비교축을 공유하는 열·행, 차이 강조표 | 대상별 조건·단위·누락 항목을 유지 |
| 얼마나 변했나 | 전후 값과 차이, 적절한 축을 가진 추세 | 기간·기준값·부호·축 범위·표본을 유지 |
| 어떻게 진행되나 | 방향이 드러나는 단계·흐름 | 선후·조건·반복·예외를 보존 |
| 무엇이 연결되나 | 역할별 노드와 방향 있는 연결 | 연결선의 의미와 실제 관계를 검증 |
| 무엇을 선택하나 | 기준·선택지·근거·미확인으로 구성한 판단표 | 없는 순위·점수·결론을 만들지 않음 |

각 장에 주장 하나만 강제하지 않는다. 한 장에서 독자가 따라야 할 핵심 관계가 무엇인지 정하고 보조 정보는 그 관계를 지지하도록 배치한다. 정보가 많으면 목적에 맞게 나누거나 독자의 참조용 밀도를 명시한다. 제목은 자료가 뒷받침하는 범위에서 결론형으로 쓸 수 있고, 근거가 불충분하면 질문이나 중립 제목을 쓴다.

## 구도와 문장

- 페이지의 가장 중요한 내용을 시각적으로 먼저 읽히게 하고, 가까운 항목은 함께 묶으며, 비교 항목은 같은 축과 간격을 공유한다. 같은 강조가 여러 개라면 강조를 줄여 우선순위를 만든다.
- 제목·주요 수치·설명·출처의 역할을 크기, 굵기와 위치로 구별한다. 본문과 라벨이 실제 표시 크기에서 읽히는지 점검하고, 넘치면 글자 축소만 반복하지 말고 내용·구조·면적을 다시 설계한다.
- 한글 조사·괄호·수치 단위가 어색하게 갈라지지 않는지, 긴 고유명사나 영어 혼용 때문에 줄이 밀리지 않는지 확인한다. 독자가 필요한 출처와 조건은 임의로 삭제하지 않는다.
- 사실이나 설명이 필요한 곳을 빈 장식으로 채우지 않는다. 한눈에 이해시키기 위해 비교 기준과 관계가 희생되면 내용을 보완한다.

## 짧은 가상 예

가상 수치가 작업 전 100분, 작업 후 70분이면 첫 장은 `100 → 70분`과 관찰 조건을 중심으로 놓고 차이 30분을 보조한다. 둘째 장에서는 작업 전후 단계를 선으로 연결해 달라진 위치를 표시한다. 셋째 장에서는 장점·적용 조건·미확인을 같은 행으로 비교한다. 이는 시각 구성 예시이며 실측 결과나 모든 발표자료의 고정 서식이 아니다.
