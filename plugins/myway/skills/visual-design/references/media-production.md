# 매체별 제작과 확인

| 매체 | 설계 시 우선 확인 | 결과물 검증 |
| --- | --- | --- |
| HTML·앱 | 화면 크기, 정보 위계, 상호작용과 빈·오류 상태 | 요청된 뷰포트의 렌더, 기능·키보드·접근성을 각각 확인 |
| 이미지·도식 | 최종 표시 크기, 내용과 배경의 대비, 정확한 연결 관계 | 원본과 사용될 크기의 가독성·방향·크롭 확인 |
| PPTX | 발표와 공유 용도, 장표별 메시지, 요청된 텍스트·차트 편집성 | 모든 요청 슬라이드 렌더 및 필요한 개체 재열기·편집 확인 |
| DOCX | 제목 스타일, 본문·표·캡션, 문서의 읽는 순서 | 구조 재열기와 필요한 페이지 렌더·표 분할 확인 |
| PDF | 출력 크기, 폰트와 이미지, 원본과 같은 내용 | 요청된 모든 페이지 렌더, 텍스트·링크·태그는 별도 확인 |

사용자가 HTML 초안을 승인한 뒤 편집 가능한 PPTX를 원하면, 각 출력이 같은 콘텐츠·레이아웃 모델에서 나오도록 설계할 수 있다. HTML을 별도로 디자인한 뒤 좌표가 같다는 이유만으로 PPTX 결과가 동일하다고 보지 않는다. 두 출력의 텍스트·좌표·스타일을 대조하고, 글꼴·줄바꿈·자동 맞춤·이미지 크롭을 각각 실제 렌더로 확인한다. 미지원 기능이나 대조 실패를 숨기지 않는다. 픽셀 동일성은 보장하지 않으며, HTML 승인 후에도 최종 PPTX를 확인한다. 반응형 웹이나 긴 DOCX에는 한 장표의 고정 좌표를 강제하지 않는다.

자동 구조 검사는 잘림·읽기 순서·편집성·미적 완성도를 모두 증명하지 않는다. 해당 렌더러, 크기와 확인한 범위를 남기고, 사용자의 도구 사용 선호와 실제 권한 경계를 따른다.
