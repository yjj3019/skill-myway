# 영문 기술 문서 편집

영문 README와 기술 문서는 독자와 요청된 편집 강도에 맞춰 고친다. 한국어 말투·블로그 프로필을 영문 기본값으로 적용하지 않는다. 기존 철자 체계와 작성자의 어조, 제목·목록·코드 구조를 사용자의 요청 범위 안에서 유지한다.

1. 문장과 문단이 독자에게 전달하는 행동, 조건, 결과를 먼저 확인한다. 독자가 이미 이해한 정보를 반복하는 문구나 근거 없는 강조는 문맥을 보고 줄인다.
2. 추상적인 주장을 구체화할 때는 원문에 있는 근거만 사용한다. 확인되지 않은 성능·경험·보증을 추가하지 않는다. 정확한 의미에 필요한 수동태와 기술 용어 반복은 남긴다.
3. 명령·옵션·경로·URL·제품명·수치·단위·인용은 원문과 비교한다. 부정, 가능성, 시제, 적용 대상과 예외도 의미 단위로 대조한다. 코드 블록을 편집하도록 명시하지 않았다면 실행 가능한 내용을 고치지 않는다.
4. 문장별 표현이 바뀌지 않아도 자연스럽고 정확하면 그대로 둔다. 요청받으면 주요 수정 이유를 제시하되 기본 응답에 비교표를 강제하지 않는다.

이 절차는 작성 주체의 판별이나 탐지 결과를 보장하지 않는다. 편집 전후 정확성·자연스러움은 실제 사례별 평가가 필요하다.
