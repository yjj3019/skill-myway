# 임원 요약(1페이지)

의사결정자가 짧은 시간에 판단할 수 있도록 한 페이지로 압축한다. 배경 설명보다 결론과 요청을 앞세운다.

## 구조

1. **결론** — 1~2문장. 무엇을 권고하거나 보고하는지.
2. **핵심 근거** — 3개 이내. 각 근거에 출처·기준일을 붙인다.
3. **영향** — 비용·일정·위험·범위. 수치가 있으면 단위와 산출 조건을 쓴다.
4. **요청·결정 사항** — 승인·선택·지원이 필요한 항목. 없으면 "결정 요청 없음"으로 쓴다.
5. **한계·미확인** — 결론의 신뢰도에 영향을 주는 항목만.

## 작성 규칙

- 결론을 첫 문단에 쓴다. 서론·배경으로 시작하지 않는다.
- 모든 수치에 출처와 기준일을 붙인다. 추정치는 추정임을 표시한다.
- 선택지를 제시하면 추천안과 이유를 함께 쓴다.
- 길이는 한 페이지를 넘기지 않는다. 상세는 부록이나 링크로 분리한다.

## 흔한 실패

- 배경 나열로 결론이 늦어짐
- 근거 없이 확신하는 어조
- 요청 사항이 빠져 결정자가 할 일이 불분명함
- 위험·한계를 빼서 낙관적으로 읽힘
