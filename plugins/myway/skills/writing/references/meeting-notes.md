# 회의록과 결정 기록

회의의 결론과 후속 행동이 사라지지 않게 남긴다. 발언 기록보다 결정과 할 일이 핵심이다.

## 구조

1. **일시·참석·목적** — 한 줄씩. 온라인/대면 구분이 필요하면 적는다.
2. **안건** — 논의한 순서대로. 안건마다 결론을 붙인다.
3. **결정** — 확정된 것만. 누가 결정했는지, 조건이 있는지 적는다.
4. **할 일** — 항목, 담당, 기한, 상태. 담당이 없으면 "미정"으로 둔다.
5. **보류·쟁점** — 결론이 나지 않은 것과 다음 회의에서 다룰 것.
6. **공유 범위** — 민감 내용이 있으면 공유 대상과 제한을 적는다.

## 규칙

- 발언을 길게 옮기지 않는다. 결정에 영향을 준 요지만 요약한다.
- 확인되지 않은 결정을 확정처럼 쓰지 않는다. "합의 필요"로 표시한다.
- 할 일에는 반드시 담당과 기한을 붙이거나, 둘 다 없으면 "미정"으로 남긴다.
- 녹취·메모에 개인정보나 내부 식별자가 있으면 옮기지 않는다.
- 같은 회의를 다시 정리할 때 이전 결정과 바뀐 점을 표시한다.

## 출력

- 제목: 날짜 + 안건 요약.
- 본문: 위 구조 순서.
- 끝에 다음 회의 안건 후보가 있으면 짧게 덧붙인다.
