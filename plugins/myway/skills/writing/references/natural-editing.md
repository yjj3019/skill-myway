# 자연스러운 문체와 사실 보존

문체 편집은 탐지기 회피가 아니라 독자의 이해와 작성자의 의도를 돕는 작업이다. 판정 도구의 결과나 특정 단어만으로 작성 주체를 단정하지 않는다.

1. 독자에게 필요한 결론과 근거를 찾아 반복되는 도입·전환·요약을 문맥에 맞게 줄인다. 필요한 예외와 주의는 남긴다.
2. 추상적 평가를 제공된 사실과 관찰로 구체화한다. 실제 경험, 감정, 인용, 숫자와 사례는 없는 것을 만들지 않는다.
3. 문장 길이와 문단 구조를 내용의 관계에 맞춘다. 일부러 불규칙하게 만들거나 오탈자·구어체를 삽입하지 않는다.
4. 수정 전후의 부정, 조건, 인과관계, 확실성, 인용과 기술 문자열을 대조한다. 직접 인용이나 의도적인 반복은 보존한다.
5. 여러 버전을 비교할 때는 명료성, 원문 충실성, 독자와 매체 적합성을 기준으로 평가한다. 독립 판정 없이 개선 효과나 탐지 회피를 보장하지 않는다.
