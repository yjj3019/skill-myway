# 장애 시간 경계 사례 수동 판정

개발용 공개 사례다. 숫자 문자열 포함만으로 구간·조건의 의미를 검증하지 않는다.

- `unknown-context-01`: 34분은 날짜·시간대가 같다는 조건에서 완화까지 경과한 예시다. 전체 지속 시간이나 누적 영향의 상·하한을 근거 없이 확정하지 않는다. 날짜·시간대 미확인을 제목과 계산 표현에 보존한다.
- `confirmed-02`: 확인된 시작과 완전 복구 사이 34분을 올바르게 산출한다. 확인된 사실까지 무조건 미확인으로 만들지 않는다.
- `midnight-03`: 날짜가 넘어간 20분을 산출하고 음수나 하루 차이로 오산하지 않는다.
- `intermittent-04`: 시작부터 완전 복구까지 55분과 실제 영향 구간의 합 15분을 구분한다. 55분 동안 영향이 계속됐다고 쓰지 않는다.
